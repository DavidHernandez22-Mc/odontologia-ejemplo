# Odontología Ejemplo

Página web de una clínica dental: una sola página en HTML, CSS y JavaScript, sin dependencias.

- Imagen fija que cambia con cada sección mientras bajas.
- Tratamientos, primera visita, equipo, precios, preguntas frecuentes y contacto.
- Mapa interactivo de la boca: el paciente toca dónde le duele, elige qué siente y recibe una orientación con tiempo y precio, más un enlace a WhatsApp con el mensaje escrito.

Para verla en local, abre `index.html` o sirve la carpeta (`python3 -m http.server`).

Los datos de la clínica (dirección, teléfono, equipo, precios) son de ejemplo. Fotografías de Unsplash, con créditos en el pie de página.
